# Task 3 - Web Traffic Analytics

This task analyzes website session data to understand visitor behavior.

## Work Done
- Loaded and inspected website traffic data.
- Calculated average product page time.
- Checked bounce and exit rates.
- Counted purchase and non-purchase sessions.
- Created a chart showing product page visits.

- Pandas
- Matplotlib
- Jupyter Notebook
