# Task 2 - Customer Churn Analysis

This task analyzes customer data to understand why customers leave a subscription service.

## Work Done
- Loaded and inspected customer data.
- Counted customers who left and stayed.
- Calculated the churn rate.
- Compared monthly charges.
- Created a bar chart.

## Tools Used
- Python
- Pandas
- Matplotlib
- Jupyter Notebook

## Files
- `data/` - Customer dataset
- `src/task2.ipynb` - Analysis code
- `output/` - Analysis results and chart
